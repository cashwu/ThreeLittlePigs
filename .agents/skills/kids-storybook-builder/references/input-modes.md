# Input Modes

## 文字模式

1. 將使用者明確標示的頁碼、頁界或檔案順序視為 authoritative。
2. 保留原始拼字、引號、段落與有意義換行；可正規化行尾空白與空白行，但不要靜默修正文句。
3. 若原文同時含頁碼與正文，頁碼只作 metadata，不成為朗讀句子。
4. 若一頁由多則訊息組成，合併前先確認訊息中的頁標示；沒有頁標示時依收到順序，並在摘要記錄這個推導。
5. 發現拼字或文法疑似錯誤時，先保留原文；只有使用者要求校訂，或錯誤會破壞解析／TTS 時才提出具體修正。

## 圖片模式

1. 先列出所有圖片，依可見頁碼排序；沒有頁碼時使用檔名中的自然數字順序，再沒有時使用使用者提供順序。
2. 逐張視覺檢查，不只依賴 OCR。記錄：頁 ID、英文文字、顯示換行、段落、被裁切區域及不確定片段。
3. 忽略純裝飾文字、出版社資訊或頁眉頁腳，除非使用者要求納入；對話框、caption 與正文則依閱讀順序轉錄。
4. ASCII 引號與彎引號可在 source normalization 階段統一，但不得改變字詞。連字號、縮寫、所有格與標點會影響分句和 TTS，需特別核對。
5. 同一頁有多欄、對話泡泡或非線性版面時，以自然閱讀順序排列；若順序存在兩種合理解讀且會改變故事，詢問使用者。
6. 低信心片段不得用其他版本的故事或網路搜尋結果偷偷補齊。可用上下文提出候選，但需標明頁面與候選文字請使用者確認。
7. 圖片解析完成後，做一次 page-by-page coverage check：每張輸入圖片恰對應一個來源頁，沒有遺漏、重複或順序跳號未說明。
8. 圖片預設只作為文字與版面來源，不直接顯示在產出的網頁。只有使用者要求保留插圖時才把圖片納入 runtime assets；若使用者意圖不明且是否顯示圖片會實質改變輸出形式，先詢問。

## 文字與圖片並存

- 使用者指定文字為準：圖片只驗證頁界與換行，差異列出但不覆寫文字。
- 使用者指定圖片為準：以圖片轉錄修正文字草稿，保留差異紀錄。
- 未指定：先產生差異清單。標點或空白等不影響內容的差異可依圖片正規化；字詞、句子或頁序差異必須詢問。

## 翻譯規則

- 先完成英文分句，再逐句翻譯，避免中文句界反向污染英文 parser。
- 人名、角色性別、時態與重複句型在全書保持一致。
- 用兒童能理解的繁體中文，不增加原文沒有的教訓、情節或角色心理。
- 每頁中文陣列長度必須等於該頁英文句數；總數也必須相同。
